# Telegram PC Bridge

Локальный Tkinter-пульт: команда отправляется Telegram-боту с телефона, запущенная программа на ПК получает её, выполняет только разрешённое действие и отправляет результат обратно в Telegram.

## Команды

- `/status` — ОС, имя ПК, пользователь, Python, локальный IP, время работы Bridge, занятое и свободное место на диске.
- `/apps` — список приложений из allow-list.
- `/run notepad` — запуск разрешённого приложения.
- `/files desktop`, `/files downloads`, `/files documents` — безопасный просмотр содержимого разрешённых папок.
- `/help` — справка.

На Windows по умолчанию разрешены `notepad`, `calculator`, `explorer`.

## Ответы в Telegram

После команды бот отправляет результат обратно на телефон. Ошибки тоже возвращаются сообщением. После получения голосового бот подтверждает, что файл сохранён на ПК.

## Защита

В окне есть поле **Ваш Telegram User ID**. После заполнения команды от других аккаунтов игнорируются. Рекомендуется обязательно заполнить его перед использованием управления ПК.

Программа намеренно **не выполняет произвольные shell/cmd/PowerShell-команды**. Доступны только действия из allow-list.

## Запуск

```bash
python main.py
```

Токен и User ID сохраняются локально в `config.json`; файл исключён из Git через `.gitignore`.

Если User ID пока неизвестен: запустите Bridge без него, отправьте боту обычное сообщение и посмотрите User ID в журнале Tkinter. Затем остановите Bridge, впишите ID и запустите снова.
