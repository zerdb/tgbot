# Telegram PC Bridge

Локальное Tkinter-приложение, которое слушает Telegram-бота через Bot API и показывает входящие сообщения на компьютере.

## Сейчас умеет

- подключаться по Bot Token;
- получать сообщения через long polling;
- показывать текстовые сообщения в Tkinter;
- получать голосовые сообщения;
- скачивать voice-файлы в локальную папку `downloads`;
- показывать Chat ID и User ID отправителя;
- работать без сторонних Python-библиотек.

## Запуск

```bash
python main.py
```

Вставьте токен, полученный у BotFather, в поле программы и нажмите «Запустить».

Токен сохраняется только локально в `config.json`. Этот файл добавлен в `.gitignore` и не должен попадать в Git.

## Важно

Для работы компьютеру нужен интернет: приложение локальное, но общается с Telegram Bot API.

На текущем этапе голосовое сообщение скачивается как OGG-файл и отображается в журнале. Распознавание речи и выполнение команд намеренно пока не добавлены.
