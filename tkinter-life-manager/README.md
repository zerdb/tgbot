# Life Manager

Крупное desktop-приложение на чистом Python + Tkinter + SQLite.

## Что внутри

- Dashboard со статистикой;
- менеджер задач: категории, приоритеты, сроки, выполнение;
- трекер ежедневных привычек;
- заметки с локальным хранением;
- SQLite база создаётся автоматически;
- тёмный интерфейс и боковая навигация;
- никаких внешних зависимостей.

## Запуск

```bash
python main.py
```

Данные хранятся локально в `life_manager.db` рядом с программой.

## Идея

Это основа персонального desktop-органайзера. Архитектура уже разделена на интерфейс и слой базы данных, поэтому дальше можно добавлять календарь, аналитику, таймер Pomodoro, поиск, экспорт/импорт, настройки тем и резервное копирование.
