# GigaAM Fleet Admin — первый прототип

Центральная инвентаризация для одной локальной сети: сервер на Windows 11, агенты на Windows 10/11, DHCP поддерживается. Python 3.10+, только стандартная библиотека.

## Реализовано
- Регистрация каждого агента по уникальному UUID.
- IP определяется сервером по входящему соединению и обновляется при смене DHCP-адреса.
- Сбор имени ПК, пользователя, MAC, версии Windows, CPU, RAM и дисков.
- SQLite на центральном ПК и веб-панель со статусами онлайн/офлайн.
- Heartbeat раз в минуту; онлайн — контакт за последние 3 минуты.
- Общий секрет для приёма телеметрии. Удалённого выполнения команд нет.

## Центральный ПК (Windows 11)
В PowerShell из этой папки:
```powershell
py server.py
```
Сервер напечатает токен регистрации. Сохрани его — это секрет.
Узнай LAN IPv4 командой `ipconfig`. Разреши входящий TCP-порт 8765 только из локальной подсети в Windows Firewall. Не пробрасывай порт в интернет.

Открой в браузере `http://127.0.0.1:8765/`, введи токен в поле сверху и нажми «Подключить». Токен хранится в localStorage этого браузера. Агентам передавай тот же токен только по доверенной сети.

## Рабочий ПК (Windows 10/11)
Скопируй эту папку на тестовый компьютер и запусти:
```powershell
py agent.py --server http://192.168.1.10:8765 --token ВСТАВЬ_ТОКЕН
```
Замени IP на адрес центрального ПК. UUID, адрес и токен сохраняются в `%PROGRAMDATA%\GigaAMFleetAgent\agent.json`. При повторном запуске параметры можно опустить.

## Важные ограничения прототипа
- Сначала проверь на 1–2 тестовых ПК, не разворачивай сразу на всю организацию.
- HTTP не шифруется: используй только доверенную LAN. Токен может быть перехвачен в сети.
- Токен общий для пилота; позже заменим на индивидуальные ключи агентов и TLS.
- Агент пока запускается вручную, это ещё не Windows-служба.
- Пока нет удалённого управления, установки ПО, перезагрузки и произвольных команд.

Проверка синтаксиса:
```powershell
py -m py_compile server.py agent.py
```
