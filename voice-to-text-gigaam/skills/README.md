# Навыки GigaAM

Каждый навык — самостоятельный модуль с именем, описанием и обработчиком действий.
Навыки не импортируют внутренние функции друг друга: они вызывают другой навык через
общий `SkillContext.call()` и получают единый `SkillResult`.

## Первый демонстрационный процесс: сводка продаж

1. `files.find` — поиск исходной книги по папке и шаблону.
2. `excel_reader.read_table` — чтение таблицы из книги.
3. `calculations.group_sum` — группировка по выбранному столбцу и точное суммирование.
4. `excel_writer.write_group_report` — создание отдельной книги отчёта.

Для первого этапа намеренно не угадываются названия колонок: вызывающий код должен явно
передать `group_by` и `sum_column`. Это защищает от неправильного отчёта. Исходная книга
открывается только для чтения, а существующий файл назначения никогда не перезаписывается.

## Протокол

Сообщение содержит `task_id`, `from_skill`, `to_skill`, `action` и `inputs`.
Ответ содержит тот же `task_id`, имя навыка, статус, результат или описание ошибки.
Данные результата должны быть сериализуемы в JSON. Для передачи между навыками
используйте этот контракт, а не вызовы внутренних методов соседнего модуля.

## Ограничения текущего этапа

- Поддерживаются `.xlsx` и `.xlsm`; старый бинарный `.xls` пока не поддерживается.
- Формулы читаются как сохранённые Excel значения (`data_only=True`); если Excel не
  пересчитал формулы перед сохранением, значения могут быть пустыми.
- Это библиотека навыков и проверяемый workflow, а не универсальное понимание произвольной
  голосовой просьбы. Голосовой маршрутизатор подключается отдельным безопасным этапом.
