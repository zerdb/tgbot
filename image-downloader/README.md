# Image Downloader

Python-скрипт для скачивания изображений со страницы сайта.

## Возможности
- поиск изображений в обычных и lazy-load атрибутах;
- выбор наиболее крупного варианта из `srcset`;
- попытка заменить URL миниатюры на оригинальное изображение;
- поддержка встроенных base64-изображений;
- повторные запросы при временных HTTP-ошибках;
- пропуск уже скачанных файлов;
- сохранение HTML страницы для отладки.

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python downloader.py
```

Адрес страницы и параметры скачивания задаются в начале `downloader.py`.
