# Tkinter Tetris

Полноценный классический Tetris на чистом Python + Tkinter, без сторонних библиотек.

## Возможности

- 7 классических фигур и 7-bag генератор;
- уровни с постепенным ускорением;
- подсчёт очков и линий;
- hard drop и soft drop;
- ghost piece;
- следующая фигура;
- пауза и быстрый рестарт;
- рекорд в рамках текущего запуска;
- управление стрелками или WASD.

## Запуск

```bash
python tetris.py
```

## Управление

- Left / Right или A / D — движение;
- Down или S — ускоренное падение;
- Up, W или X — поворот;
- Space — мгновенный сброс;
- P или Escape — пауза;
- R — новая игра.
